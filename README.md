# NMEA Link

## Overview
NMEA Link is a portable diagnostic and test device designed for monitoring and generating NMEA 0183 serial data used in marine navigation and communication systems.

It is intended for technicians and engineers performing commissioning, troubleshooting, validation, and bench testing of marine electronic equipment.

The device operates fully standalone and does not require any external software. All interaction is performed through a built-in Wi-Fi captive portal using a standard web browser.

---

## Main Features
- NMEA 0183 real-time monitoring  
- NMEA sentence generation (predefined and custom)  
- Standalone portable operation  
- Wi-Fi captive portal access  
- Embedded web interface (monitor & generator)  
- OTA (Over-The-Air) firmware update  
- Multi-baudrate UART support  

---

## Technical Highlights
- ESP32-based embedded system  
- UART communication (RS232 / RS422 / RS485)  
- NMEA 0183 parsing with checksum validation  
- UDP data transmission (port 10110)  
- Real-time data processing  
- Embedded web server (HTML / CSS / JavaScript)  
- PCB design using Altium Designer  

---

## Engineering Approach
The device was designed as a self-contained and portable diagnostic tool to simplify onboard and workshop troubleshooting without requiring external software.

---

## Challenges Solved
- Reliable parsing of NMEA sentences under noisy conditions  
- Stable Wi-Fi captive portal implementation  
- Real-time data handling without packet loss  
- Integration of monitoring and generation features
